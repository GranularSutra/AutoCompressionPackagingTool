# 自动压缩打包工具

## 功能特点
- 🚀 拖拽即可压缩，操作简单
- 📅 自动添加时间戳，避免文件名冲突
- 📁 支持文件和文件夹压缩
- 🔄 支持同时拖拽多个项目
- 🐍 纯Python实现，无需额外依赖

## 系统要求
- Python 3.6 或更高版本
- Windows / macOS / Linux

## 使用方法
直接拖拽到Python脚本（推荐）
1. 将 `auto_zip.py` 放在任意位置
2. 选择要压缩的文件或文件夹
3. 拖拽到 `auto_zip.py` 文件上
4. 自动生成带时间戳的zip文件
